# Mirror · 会对话的个人主页

> 一面既能照给访客、也能照给自己的镜子。

大多数个人主页是"静态展板"——访客扫一眼就关掉。Mirror 不一样：它内置了一个基于我真实资料的 **AI 分身**，能 24 小时替我回答"他是谁""他喜欢什么"；而对站长自己，它还藏着一个私密的**内观**空间，用 AI 帮我复盘与反思。

**线上地址**：https://chawaicha.github.io/

---

## ✨ 功能特性

| 模块 | 说明 |
|---|---|
| 🪞 About Me | 个人名片、座右铭与标签；彩色粒子动态背景；昼夜模式；首次访问开场动画 |
| 🌍 我的世界 / 📖 手记 | 个人内容展示与记录 |
| 💬 留言板 | 访客注册昵称后留言，云端持久化 |
| 🤖 AI Mirror | **访客分身**：基于"公开资料库"回答关于我的问题，回复支持 markdown 渲染 |
| 📚 资料库管理 | 站长后台：持续投喂"关于我的事实"，公开 / 私密两级分类 |
| 🪷 内观 | **站长专属**：AI 结合公开 + 私密资料，帮助自我反思 |
| 🛡 安全防护 | Cloudflare 人机验证 + 访客每日 20 条限额 + 数据库行级安全（RLS） |

## 🏗 技术架构

```
访客浏览器                    Supabase 云端                 DeepSeek
───────────                  ──────────────────            ─────────
index.html  ── 提问 ──▶  Edge Function（mirror-chat） ──▶  Chat API
(单文件应用)                │
                            ├─ 校验：人机验证票据 / 每日限额 / 站长身份
                            ├─ 取数：公开资料库（访客）或公开+私密（站长）
                            └─ 组装提示词后调用 AI，密钥不落地前端
```

- **前端**：单文件 `index.html`（HTML + CSS + 原生 JavaScript），零构建，托管于 GitHub Pages
- **后端**：[Supabase](https://supabase.com)（PostgreSQL + Auth + Edge Functions）
- **AI**：DeepSeek API，经边缘函数中转
- **防护**：Cloudflare Turnstile 人机验证（免费、无感）

## 🔐 隐私与安全设计

本项目最核心的设计决策：

1. **双层资料库**：AI 能"看到"的事实分为公开 / 私密两级，存于独立数据表；
2. **物理隔离**：私密表通过 RLS（行级安全）锁死，仅站长本人可读，访客 AI 在代码层面就接触不到；
3. **AI 封口令**：访客分身的人设规则中明令禁止提及"资料库 / 私密 / 权限"等概念；
4. **密钥不出服务端**：AI 密钥、数据库高权限密钥全部保存在边缘函数环境变量中；
5. **防刷**：人机验证 + 每日限额，控制 API 成本。

## 🚀 本地运行

纯静态单文件，任意静态服务器即可预览：

```bash
npx serve .          # 或
python -m http.server
```

> 云端功能（留言板 / AI）需要自己的 Supabase 项目与密钥配置，详见仓库内说明。
